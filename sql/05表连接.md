## 表连接

### 1.1 内连接

​	从多张表格里选取列，通过某个表中的唯一标识，比如顾客id列来识别每笔订单的顾客信息；在SQL中有两种类型的连接，内连接和外连接；INNER关键字可写可不写（默认采用内连接）通过JOIN连接多表，通过ON加设关联条件；

```sql
SELECT order_id, first_name, last_name, orders.customer.id
FROM orders
INNER JOIN customers
ON order.customer_id = customers.customer_id
```

​	通过查询语句，告诉MySQL每当连接orders表和customers表，要确保orders表里的顾客id列与customers表里的顾客id列一致；

​	当多张表中存在相同列字段时，需要添加表名称前缀来帮助MySQL明确返回哪张表的对应列，否则就会报错“**列名不明确**”；

​	紧跟在每个表后，可以通过别名使查询语句更加简洁，假设给了表一个别名，后续其他地方也一定要用这个别名，否则MySQL无法执行；

```sql
SELECT order_id, first_name, last_name, o.customer.id
FROM orders o
JOIN customers c
ON o.customer_id = c.customer_id
```

​	练习：通过连接products表和order items表，查询返回产品id和名字，连同order items表的数量和单价；

```sql
SELECT p.product_id, name, quantity, oi.unit_price
FROM products p
JOIN order_items oi
ON p.product_id = oi.product_id
```

### 1.2 跨数据库连接

​	将分散在多个数据库的表中的列字段合并起来；连接其它数据库表时，要加上对应的数据库名称作为前缀，类似于对象语法；根据USE关键字应用的数据库，只需要给不在当前数据库的表加前缀；

```sql
USE sql_store;
SELECT * FROM order_items oi
JOIN sql_inventory.products	p
ON oi.product_id = p.product_id
```

### 1.3 自连接

​	将一张表与它自身连接；例如HR表中含有公司中所有人员的信息，通过“**reports_to**”字段来区分该人员的上级领导是谁，所以我们可以通过当前表与自身连接进行查询；通过设置别名区别表和列字段；

```sql
USE sql_hr;
SELECT e.employee_id, e.first_name, m.first_name AS manager
FROM employees e
JOIN employees m
ON e.reports_to = m.employee_id
```

### 2.1 多表连接

​	连接多张表合并查询（三张表以上连接）；

```sql
USE sql_store;
SELECT
	o.order_id,
	o.order_date,
	c.first_name,
	c.last_name,
	os.name AS status
FROM orders o
JOIN customers c
ON o.customer_id = c.customer_id
JOIN order_statuses os
ON o.status = os.order_status_id
```

​	练习：通过sql_invoicing数据库中payments、payment_methods、client表做连接，查询顾客付款信息、日期、客户名称等；

```sql
USE sql_invoicing;
SELECT
		p.invoice_id,
		c.name,
    p.date,
    p.amount,
    pm.name AS payment_method
FROM payments p
JOIN payment_methods pm
ON p.payment_method = pm.payment_method_id
JOIN clients c
ON p.client_id = c.client_id
```

### 2.2 复合连接条件

​	上面的例子都用了单一列唯一识别某张表的行，例如customers表中顾客ID列是唯一识别了该表中里的每行（不存在重复的ID）但是在其他情况下，会有某张表中无法使用单一列来准确识别表中列的情况（例如order_items表）

​	比如某个订单中有3个项目，分别是产品ID146，每个产品对应数量和价格，所以可以使用这两列值的结合，就能唯一识别每一个订单的项目；

​	打开order_items表设置，可以看到表中有两个主键，这种形式称为复合主键，包含了超过一列；

```sql
SELECT oin.note_id, oin.note
FROM order_items oi
JOIN order_item_notes oin
ON oi.order_id = oin.order_id AND oi.product_id = oin.product_id
```

 ### 2.3 隐式连接

​	尽量不使用隐式连接语法，如果忘记写查询条件时，会查询到多条记录的交叉表；

```sql
SELECT * FROM orders o, customers c
WHERE o.customer_id = c.customer_id
```

### 3.1 外连接

​	内连接是多表连接默认使用的方式，通过ON关键字后添加筛选条件，过滤掉不符合结果的记录；外连接可以在JOIN关键字前添加LEFT左连接和RIGHT右连接；LEFT左连接返回左表所有记录忽略ON添加的筛选条件（比如例子中左表customers）RIGHT反之亦然；

​	案例中当使用RIGHT右连接时会返回与内连接相同的内容，如果想用右连接且查询到所有顾客，就需要交换一下左右表编写顺序；

​	OUTER关键字可有可无，就像INNER关键字一样，默认形式；

```sql
SELECT c.customer_id, c.first_name, o.order_id
-- FROM customers c LEFT JOIN orders o
-- FROM orders o RIGHT JOIN customers c 
FROM customers c LEFT OUTER JOIN orders o
ON c.customer_id = o.customer_id
```

​	练习：查询product_id、name、quantity需要连接产品表和订单项目表，查看所有产品被订购的次数；

```sql
SELECT p.product_id, p.name AS product_name, oi.quantity
FROM products p LEFT JOIN order_items oi
ON p.product_id = oi.product_id
```

### 3.2 多表外连接

​	在多表外连接中尽量都使用LEFT左连接，避免左右连接都使用，容易导致语义化不清晰；

```sql
SELECT c.customer_id, c.first_name, o.order_id, sh.shipper_id, sh.name AS shipper_name
FROM customers c LEFT JOIN orders o
ON c.customer_id = o.customer_id
LEFT JOIN shippers sh
ON o.shipper_id = sh.shipper_id
```

​	练习：查询订单日期、订单id、顾客名称、发货人、状态列；

```sql
SELECT
		o.order_id,
    o.order_date,
    c.first_name AS customer,
    sh.name AS shipper_name,
    os.name AS status
FROM orders o
JOIN customers c
ON o.customer_id = c.customer_id
LEFT JOIN shippers sh
ON o.shipper_id = sh.shipper_id
JOIN order_statuses os
ON o.status = os.order_status_id
ORDER BY o.order_id
```

### 3.3 自外连接

​	回顾内自连接的案例，获取所有员工和管理人员；

```sql
USE sql_hr;
SELECT e.employee_id, e.first_name, m.first_name AS manager
FROM employees e LEFT JOIN employees m
ON e.reports_to = m.employee_id
```

### 4.1 USING子句

​	当查询变得更复杂时，ON连接条件会让查询语句很难理解，当查询的两个表名列字段名称是完全相同的，在MySQL中通过USING简化查询；

```sql
SELECT o.order_id, c.first_name, sh.name AS shipper
FROM orders o JOIN customers c USING (customer_id)
JOIN shippers sh USING (shipper_id)
```

​	在连接表时存在复合主键组合时添加多个条件；

```sql
SELECT oin.note_id, oin.note
FROM order_items oi JOIN order_item_notes oin
USING (product_id, order_id)
```

​	练习：在sql_invoicing数据库中查询支付表日期、客户、数额、付款方式；

```sql
USE sql_invoicing;
SELECT p.date, c.name AS client, p.amount, pm.name AS payment_method
FROM payments p JOIN clients c USING (client_id)
JOIN payment_methods pm
ON p.payment_method = pm.payment_method_id
```

### 4.2 自然连接

​	MySQL更加简洁的连接方式，不推荐使用；不指定关联的条件列，数据库引擎会基于共同的列进行连接，这种方式容易失控查询意外结果；

```sql
SELECT o.order_id, c.first_name
FROM orders o NATURAL JOIN customers c
```

### 4.3 交叉连接

​	结合或连接第一张表和第二张表的每条记录；交叉连接的应用案例，例如产品型号表，大小、颜色，想要将所有型号和所有颜色进行组合；

```sql
SELECT c.first_name AS customer, p.name AS product
-- 交叉连接显示语法
-- FROM customers c CROSS JOIN products p
-- 交叉连接隐式语法
FROM customers c, orders o
ORDER BY c.first_name
```

### 5.1 UNION运算符

​	在SQL中我们可以结合多张表的行联合查询；通过UNION运算符可以合并多段查询的数据；

```sql
SELECT order_id, order_date, "Active" AS status
FROM orders WHERE order_date >= "2019-01-01"
UNION
SELECT order_id, order_date, "Archived" AS status
FROM orders WHERE order_date < "2019-01-01"
```

​	也可以基于不同表写查询语句，并将结果合并到一个结果集；查询返回的列数量保持一致，否则就会报错；根据第一段查询的字段作为返回的列名称；

```sql
-- SELECT first_name FROM customers UNION
SELECT first_name, last_name FROM customers UNION
SELECT name FROM shippers
```

​	练习：查询返回顾客id、名字、积分、类型；顾客表中没有类型字段，所以要根据他们的积分大小赋值，小于2000青铜Bronze、2000到3000白银Silver、大于3000黄金Gold；结果用名称排序；

```sql
SELECT customer_id, first_name, points, "Bronze" AS type
FROM customers WHERE points < 2000 UNION
SELECT customer_id, first_name, points, "Silver" AS type
FROM customers WHERE points BETWEEN 2000 AND 3000 UNION 
SELECT customer_id, first_name, points, "Glod" AS type
FROM customers WHERE points > 3000
ORDER BY first_name
```
