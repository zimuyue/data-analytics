## 内置函数

### 1.1 数值函数

```sql
-- 四舍五入
SELECT round(5.76, 1);
SELECT round(5.7636, 2);
SELECT round(3.7636, -1); -- 0
SELECT round(5.7636, -1); -- 10
-- 截取位数
SELECT truncate(5.7345, 2); -- 5.73
SELECT truncate(5.7345, 0); -- 5
SELECT truncate(5.7345, -1); -- 0
SELECT truncate(5.7345, 5); -- 5.7345
-- 上限函数
-- 返回大于或等于参数的最小整数
SELECT ceiling(5.7); -- 6
SELECT ceiling(5.2); -- 6
-- 下限函数
SELECT floor(5.7); -- 5
-- 绝对值函数
SELECT abs(5.2); -- 5.2
SELECT abs(-5.2); -- -5.2
-- 随机数[0-1]
SELECT rand();
```

### 1.2 文本函数

```sql
-- 文本长度
SELECT length('sky');
-- 转大写
SELECT upper('sky');
-- 转小写
SELECT lower('SKY');
-- 去除左空格
SELECT ltrim('  sky');
-- 去除右空格
SELECT rtrim('sky  ');
-- 去除前后空格
SELECT trim('  sky  ');
-- 从左截取文本
SELECT left('Kindergarten', 4); -- Kind
SELECT left('Kindergarten', 0); -- 
SELECT left('Kindergarten', -1); --
-- 从右截取文本
SELECT right('Kindergarten', 4);
SELECT right('Kindergarten', 0.5); -- n 四舍五入
-- 截取文本 文本、位置、长度
SELECT substring('Kindergarten', 3, 5); -- nderg
SELECT substring('Kindergarten', 0, 5); --
SELECT substring('Kindergarten', -1, 5); -- n
SELECT substring('Kindergarten', -2, 5); -- en
SELECT substring('Kindergarten', 7); -- garten
-- 检索指定字符位置 无视大小写
SELECT locate('n', 'Kindergarten'); -- 3
SELECT locate('kin', 'Kindergarten'); -- 1
SELECT locate('q', 'Kindergarten'); -- 0
-- 替换文本 源文本、被替换的文本、替换文本
SELECT replace('Kindergarten', 'garten', 'garden');
-- 拼接文本
SELECT concat(first_name, '-', last_name) AS full_name FROM customers;
```

### 2.1 日期函数

```sql
-- 获取当前日期时间 电脑系统日期时间
SELECT now(), curdate(), curtime();
-- 取特定日期或时间 整数值
SELECT year(now()), month(now()), day(now());
SELECT minute(now()), second(now());
-- 文本值
SELECT dayname(now()), monthname(now()); -- Wednesday
SELECT extract(YEAR FROM now()); -- 2026
```

​	练习：动态获取当前年份数据；

```sql
SELECT * FROM orders WHERE year(order_date) = year(now())
```

### 2.2 格式化日期

```sql
-- 格式化
SELECT date_format(now(), '%y'); -- 26
SELECT date_format(now(), '%Y'); -- 2026
SELECT date_format(now(), '%m %Y'); -- 11 2026
SELECT date_format(now(), '%M %Y'); -- March 2026
SELECT date_format(now(), '%M %d %Y'); -- March 11 2026
SELECT date_format(now(), '%Y/%m/%d %p %H:%i:%s'); -- 2026/11/18 PM 22:30:11
-- 时间
SELECT time_format(now(), '%H:%i %p'); -- 22:31 PM
```

### 2.3 计算日期

```sql
-- 日期增加天数
SELECT date_add(now(), interval 1 day); -- 2026-11-19 22:34:32
SELECT date_add(now(), interval 1 year);
-- 过去的日期 传递负值
SELECT date_add(now(), interval -1 day);
-- 日期减天数
SELECT date_sub(now(), interval 1 day);
-- 日期间隔 仅能返回天数间隔
SELECT datediff(now(), '2026-01-01'); -- 321
SELECT datediff('2026-01-01', now()); -- -321
-- 时间间隔 从零点开始计算
SELECT time_to_sec('09:00'); -- 32400
SELECT (time_to_sec('09:00') - time_to_sec('08:10')) / 60 / 60 AS gap_time; -- 0.83333333
```

### 3.1 IFNULL函数

​	查询表中的记录行，如果是null值则返回指定的值；

```sql
SELECT
	order_id,
	ifnull(shipper_id, 'Not assigned') AS shipper
FROM orders;
```

​	根据表中指定列的值来返回，如果指定列值也没有则返回指定值；

```sql
SELECT
	order_id,
	coalesce(shipper_id, comments, 'Not assigned') AS shipper
FROM orders;
```

​	练习：查询customer全名和电话，null值为Unknown；

```sql
SELECT
	concat(first_name, '-', last_name),
	ifnull(phone, 'Unknown')
FROM customers;
```

### 3.2 IF函数

​	之前是通过UNION运算符来合并查询结果，使用IF函数可以简化操作，IF函数测试参数可以是表达式；

```sql
SELECT
	order_id,
	order_date,
	IF(year(order_date) = year(now()), 'Active', 'Archived') AS category
FROM orders
```

​	练习：生成包含产品id、名称、订单数、订单出现次数；

```sql
SELECT
	product_id,
	name,
	count(*) AS orders,
	IF(count(*) > 1, 'Many Times', 'Once') AS frequency
FROM products JOIN order_items USING(product_id)
GROUP BY product_id, name
```

 ### 3.3 CASE运算符

​	相当于JS中的switch case语句，用来匹配不同结果的值；CASE运算符后需跟着WHEN子句，每个WHEN子句都有一个测试表达式，如果测试的值为true通过THEN后内容来返回对应的结果；ELSE确保都没有匹配上结果返回的值，最后使用END结束语句；

```sql
SELECT
	order_id,
	CASE
		WHEN year(order_date) = year(now()) THEN 'Active'
		WHEN year(order_date) = year(now()) - 1 THEN 'Last Year'
		WHEN year(order_date) < year(now()) - 1 THEN 'Archived'
		ELSE 'Futrue'
	END AS category
FROM orders
```

​	练习：简化金牌客户案例查询；

```sql
SELECT
	concat(first_name,' ',last_name) AS customer,
	points,
	CASE
		WHEN points > 3000 THEN 'Glod'
		WHEN points >= 2000 THEN 'Silver'
		ELSE 'Bronze'
	END AS category
FROM customers
```
