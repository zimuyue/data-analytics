## 复杂查询

### 1.1 子查询

​	案例：查询所有比生菜更贵的产品（Lettuce id = 3）

​	当MySQL执行查询时，优先去评估是否有子查询，执行内查询后将结果传递给外查询；同时也可以在FROM子句和SELECT子句中编写子查询；

```sql
SELECT * FROM products WHERE unit_price > (
	SELECT unit_price FROM products WHERE product_id = 3
)
```

​	练习：在sql_hr数据库查询所有收入在平均线以上的演员；

```sql
SELECT * FROM employees WHERE salary > (
	SELECT avg(salary) FROM employees
) ORDER BY salary DESC
```

### 1.2 IN运算符

​	案例：查询没有被订购的产品；

```sql
SELECT * FROM products WHERE product_id NOT IN (
	SELECT DISTINCT product_id FROM order_items
)
```

​	练习：在sql_invoicing数据库查询没有发票的客户；

```sql
SELECT * FROM clients WHERE client_id NOT IN (
	SELECT DISTINCT client_id FROM invoices
)
```

### 1.3 连接表

​	案例：在不使用子查询，通过上一个案例使用invoices表连接客户；

​	这么写的好处是在对比执行速度和代码可读性中，优先选择执行速度，假设执行效率是一致的，则应该选择易读性；

```sql
SELECT * FROM clients LEFT JOIN invoices USING(client_id)
WHERE invoice_id IS NULL
```

​	练习：在sql_store数据库查询订购生菜的客户；

```sql
SELECT customer_id,first_name,last_name
FROM customers WHERE customer_id IN (
	SELECT o.customer_id FROM order_items oi
	JOIN orders o USING(order_id)
	WHERE product_id = 3
)
-- next
SELECT DISTINCT customer_id,first_name,last_name
FROM customers c
LEFT JOIN orders o USING(customer_id)
LEFT JOIN order_items oi USING(order_id)
WHERE oi.product_id = 3
```

### 2.1 ALL关键字

​	案例：查询大于客户id=3所有发票额度的发票；

```sql
SELECT * FROM invoices WHERE invoice_total > (
	SELECT max(invoice_total) FROM invoices
  WHERE client_id = 3
)
```

​	使用ALL关键字，在执行外部查询时MySQL都会把表内每行与ALL关键字结果进行比较，如果每行的结果是大于ALL关键字内所有的结果时返回该条数据；

​	在第一个案例中子查询语句返回的单一结果值，第二个案例中子查询返回的一列值，如果不加ALL关键字MySQL无法对比条件的值；

```sql
SELECT * FROM invoices WHERE invoice_total > ALL(
	SELECT invoice_total FROM invoices WHERE client_id = 3
)
```

### 2.2 ANY关键字

​	案例：查询至少有两张发票的客户；

```sql
SELECT * FROM clients WHERE client_id IN (
	SELECT client_id FROM invoices
	GROUP BY client_id HAVING count(*) >= 2
)
```

​	使用ANY与SOME关键字（SOME是ANY的别名）查询返回任意值行；只要满足任意一个值的条件，整个表达式就会返回TRUE；ANY与IN操作符是等效的；

```sql
SELECT * FROM clients WHERE client_id = ANY(
	SELECT client_id FROM invoices
	GROUP BY client_id HAVING count(*) >= 2
)
```

### 3.1 相关子查询

​	子查询与外查询相关联（引用条件）当MySQL执行这段查询时，对外查询的每条记录执行子查询，类似于双层嵌套的FOR循环语句；相关子查询执行效率低，数据越多查询越耗时，占用更多的存储；

​	案例：查询大于所属部门平均值的客户；

```sql
SELECT * FROM employees e WHERE salary > (
	SELECT avg(salary) FROM employees WHERE office_id = e.office_id
)
```

​	练习：获取高于客户平均值的发票；

```sql
SELECT * FROM invoices i WHERE invoice_total > (
	SELECT avg(invoice_total) FROM invoices
    WHERE client_id = i.client_id
)
```

### 3.2 EXISTS运算符

​	当使用EXISTS运算符时，子查询不会给外查询返回一个结果（IN运算符）它会返回一个指令，用来说明这个子查询中是否有符合这个搜索条件的记录；如果找到符合条件的记录，将会返回TRUE给EXISTS运算符，然后EXISTS运算符会在最终结果里添加当前记录；

​	解决问题：当使用IN运算符子查询生成了很大的结果集，使用EXISTS运算符更加效率；因为使用EXISTS子查询并没有把结果集返回给外查询；

```sql
SELECT * FROM clients c WHERE EXISTS(
	SELECT client_id FROM invoices WHERE client_id = c.client_id 
)
```

​	练习：在sql_store数据库查询没有被订购的产品；

```sql
SELECT * FROM products p WHERE NOT EXISTS(
	SELECT product_id FROM order_items
    WHERE product_id = p.product_id
)
```

### 4.1 SELECT子句中子查询

​	当SELECT子句中使用表达式计算值时，对计算结果设置别名是无法在SELECT子句中使用的，除非是重写子查询语句，会导致过于冗余；通过SELECT子句获取别名字段方式来解决；

```sql
SELECT
	invoice_id,
	invoice_total,
  (SELECT avg(invoice_total) FROM invoices) AS invoice_average,
  invoice_total - (SELECT invoice_average) AS gap
FROM invoices
```

​	练习：生成每位客户id、name、total_sales、average、gap表；

```sql
SELECT
	client_id,
  name,
  (SELECT sum(invoice_total) FROM invoices WHERE client_id = c.client_id) AS total_sales,
  (SELECT avg(invoice_total) FROM invoices) AS average,
  (SELECT total_sales - average) AS gap
FROM clients c
```

### 4.2 FROM子句中子查询

​	构建虚拟表，通过FROM中插入子查询语句，必须指定子查询表别名；这种方式会让子句查询变得更加复杂，而另一种解决方式是用视图；

```sql
SELECT * FROM (
	SELECT
	client_id,
  name,
  (SELECT sum(invoice_total) FROM invoices WHERE client_id = c.client_id) AS total_sales,
  (SELECT avg(invoice_total) FROM invoices) AS average,
  (SELECT total_sales - average) AS gap
FROM clients c
) AS sales_summary WHERE total_sales IS NOT NULL
```
