## 子句

### 1.1 单表获取数据

​	查询语句第一步双击选择一个数据库执行查询语句，SQL语言是不区分大小写的，代码风格关键字最好是大写（例如USE关键字）并小写其它所有内容；

​	双击选择某个数据库后，在查询语句中如果引用了另一个数据库，结果被引用的数据库会被选中（数据库被选中状态字体加粗）

​	每个SQL语句都是由一个或多个关键字组成的，关键字（keyword）作为SQL组成部分的保留字；不能用作表或列的名字；

### 1.2 SELECT

​	SELECT从一个或多个表中检索信息；明确想要获取的列（列字段、*表示通配符用来获取所有列）FROM明确想要查询的表，最后使用分号终止每条语句；

​	快速执行查询语句快捷键：command+shift+enter；

```sql
USE sql_store;
SELECT * FROM customers
```

​	选择语句有两条子句，SELECT子句和FROM子句，但也有其他子句可以用于数据筛选和排序；

### 1.3 WHERE

​	WHERE子句筛选结果，WHERE后面可以写表达式；

```sql
WHERE customer_id = 1
```

### 1.4 ORDER BY

​	ORDER BY可选子句数据排序，明确排序结果参照的列；

```sql
ORDER BY first_name
```

### 1.5 注释

​	SQL语句中注释添加通过“--”形式；

```sql
USE sql_store;
SELECT * FROM customers
-- WHERE customer_id = 1
ORDER BY first_name
```

### 1.6 其他

​	所有的子句都是可选的，只填写数值，会根据数据库中的列是否有这样的值返回；子句的顺序（FROM、WHERE、ORDER BY）是不能改变的，否则语法错误（**is not valid at this postion**）无法执行；

​	换行符、大间隔和TAB符在执行SQL语句时都没有作用；

```sql
SELECT 1,2
-- FROM customers
-- WHERE customer_id = 1
-- ORDER BY first_name
```

### 2.1 SELECT+

​	当数据量大时，使用*号会对数据库服务器造成很大的压力，对特定的表列字段进行查询，使用**,**逗号分割列字段；

​	在列字段后加算数运算符，计算表达式（+、-、*、/、%）执行顺序参考数学计算逻辑；

​	计算后产生的结果，通过**AS**关键字设置描述性别名，如果想要别名中含有空格，添加字符串引号；

```sql
SELECT 
	first_name,
	last_name,
	points,
	-- points*10+100 AS discount_factor
	points*10+100 AS 'discount factor'
FROM customers
```

### 2.2 DISTINCT

​	DISTINCT关键字删除重复项（去重）如果检索存在多个列，不是只作用于其后的那一列，而是去重多列组合起来的不同结果；

```sql
SELECT DISTINCT state FROM customers 
```

### 2.3 练习

​	查询products表返回“name、unit price、new price”数据；

```sql
SELECT
		name,
    unit_price,
    unit_price * 1.1 AS new_price
FROM products
```

### 2.4 WHERE+

​	通过WHERE做条件筛选（filter condition）在执行查询时MySQL中查询执行引擎会遍历customers表中的所有顾客，对每条数据都会判断一次条件，如果条件为真，则在结果集中返回该条数据；	

```sql
SELECT *
FROM customers
WHERE points > 3000
```

### 2.5 比较运算符

​	GREATER THAN运算符**>**，SQL中比较运算符之一，NOT EQUAL运算符包含两个**!=**或**<>**；

```sql
-- > >= < <= = != <> !< !>
```

### 2.6 字符串

​	每当处理一串字符序列，也就是本质上的文本数据，需要添加引号，在查询条件上不区分大小写；在SQL中使用日期条件，需要给日期添加引号；

```sql
SELECT * FROM customers
-- WHERE state = 'VA'
-- WHERE state = 'va'
-- WHERE state != 'va'
-- WHERE state <> 'va'
WHERE birth_date > '1990-01-01'
```

  ### 2.7 练习

​	根据orders表，查询今年下的订单；

```sql
SELECT * FROM orders
WHERE order_date >= '2019-01-01'
```

### 3.1 逻辑操作符

​	AND与、OR或、NOT非，运算符逻辑规范与EXCEL或JS相同；执行顺序AND>OR；

```sql
SELECT * FROM customers
-- WHERE birth_date > '1990-01-01' OR points > 1000 AND state = 'VA'
WHERE birth_date > '1990-01-01' OR 
			(points > 1000 AND state = 'VA')
```

​	NOT运算符，结果取反；

```sql
SELECT * FROM customers
WHERE NOT (birth_date > '1990-01-01' OR points > 1000)
```

​	练习：从order items表中，获取订单号为6的项目且项目总价格大于30的；

```sql
SELECT * FROM order_items
WHERE order_id = 6 AND quantity * unit_price > 30
```

### 3.2 IN操作符

​	除了用OR运算符合并多个条件，还可以使用IN运算符；

```sql
SELECT * FROM customers
-- WHERE state = 'VA' OR state = 'GA' OR state = 'FL'
-- WHERE state IN ('VA','GA','FL')
WHERE state NOT IN ('VA','GA','FL')
```

​	练习：查询现货库存表products数量产品49、38、72；

```sql
SELECT * FROM products
-- WHERE quantity_in_stock IN (49,38,72)
WHERE quantity_in_stock NOT IN (49,38,72)
```

### 3.3 BETWEEN

​	假设想要获取积分介于1000和3000之间的顾客，检索某个范围内的值用BETWEEN操作符，可以使代码变的更简洁；BETWEEN的范围值是包含临界值；

```sql
SELECT * FROM customers
-- WHERE points >= 1000 AND points <= 3000
WHERE points BETWEEN 1000 AND 3000
```

​	练习：查询1990年1月1日至2000年1月1日出生的顾客；

 ```sql
 SELECT * FROM customers
 -- WHERE birth_date >= '1990-01-01' AND birth_date <= '2000-01-01'
 WHERE birth_date BETWEEN '1990-01-01' AND '2000-01-01'
 ```

### 4.1 LIKE运算符

​	检索遵循特定字符串模式的行，假设只想查询姓氏以“B”开头的顾客，使用“**%**”表示任意字符数，结果不区分大小写；使用“**_**”表示单个字符数；

```sql
SELECT * FROM customers
-- WHERE last_name LIKE 'B%'
-- WHERE last_name LIKE 'brush%'
-- WHERE last_name LIKE '%b%'
-- WHERE last_name LIKE '_y'
-- WHERE last_name LIKE '_____y'
WHERE last_name LIKE 'b____y'
```

​	练习：

​	1、获取顾客地址里包含“trail”或者“avenue”

​	2、获取手机号以9结尾的顾客

```sql
SELECT * FROM customers
-- WHERE address LIKE '%trail%' OR address LIKE '%avenue%'
-- WHERE phone LIKE '%9'
WHERE phone NOT LIKE '%9'
```

### 4.2 REGEXP运算符

​	正则表达式（regular expression）缩写，LIKE运算符在SQL中相较古老，而正则表达式在搜索字符串时极其强大；

​	“**^**”代表以什么开头；

​	“**$**”代表以什么结尾；

​	“**|**”代表包含OR的关系，多个搜索模式；

​	“**[]**”括号内字母可代表多元匹配项，例如“ge、ie、me”；

​	“**[a-z]**”括号内指定范围，避免冗余代码"[abcdef...]"；

​	正则语法[学习路径](https://docs.python.org/zh-cn/3/howto/regex.html)，[测试面板](https://regex101.com/)；

```sql
SELECT * FROM customers
-- WHERE last_name LIKE '%field%'
-- WHERE last_name REGEXP 'field'
-- WHERE last_name REGEXP '^field'
-- WHERE last_name REGEXP 'field$'
-- WHERE last_name REGEXP 'field|mac'
-- WHERE last_name REGEXP 'field$|mac|rose'
-- WHERE last_name REGEXP '[gim]e'
-- WHERE last_name REGEXP 'e[fmq]'
WHERE last_name REGEXP '[a-h]e'
```

### 4.3 IS NULL

​	通过WHERE的特殊子句，IS NULL子句查询空值的数据；

```sql
SELECT * FROM customers
-- WHERE phone IS NULL
WHERE phone IS NOT NULL
```

​	练习：查询orders表中还未发货的订单；

 ```sql
 SELECT * FROM orders
 WHERE shipped_date IS NULL OR shipper_id IS NULL
 ```

### 5.1 ORDER BY+

​	关于某一列的默认序列，将鼠标移至数据库中某一张表，选择第二个设置表图标项，在表管理编辑区中可以更改列、添加新列或删除现有列，改表名称、列名称或改顺序等等；

​	在关系型数据库中，每张表中会有一列数据前带有黄色的钥匙图标，这表示该列是主键列；主键列：这一列中的值要能够唯一识别表里的记录；说明为什么当围绕该表写查询时，数据会默认根据主键列排序；

​	通过ORDER BY指定列字段进行排序；

​	ASC默认升序（A-Z）使用DESC进行降序排序；

​	多列字段按照优先级依次排序；

```sql
SELECT * FROM customers
-- ORDER BY first_name
-- ORDER BY first_name DESC
-- ORDER BY state,first_name
ORDER BY state DESC, first_name DESC
```

​	MySQL与DBMS的一个区别是，在MySQL中可以使用任意列排序数据，无论该列是否在SELECT子句中；

```sql
SELECT first_name,last_name FROM customers
ORDER BY birth_date
```

​	别名排序，例如定义一个数字起别名，它只是一个表达式里的结果；

```sql
SELECT first_name,last_name,10 + 1 AS points
FROM customers
ORDER BY birth_date
```

​	根据查询列位置顺序进行排序（规避使用，代码语义不清晰）；

```sql
SELECT first_name,last_name FROM customers
ORDER BY 1,2
```

​	练习：查询order_items表，返回“order_id=2”按照总价降序排序；

```sql
SELECT *, quantity * unit_price AS total_price
FROM order_items
WHERE order_id = 2
ORDER BY total_price DESC
```

### 5.2 LIMIT

​	用来限制返回查询的记录条数，如果限定值超出条数范围会返回表中所有记录；

```sql
-- SELECT * FROM customers LIMIT 3
SELECT * FROM customers LIMIT 100
```

​	数据分页，通过偏移量设置，假设每页前端只展示3条数据，当前端请求携带页数参数时，比如第三页，那么偏移量就是**(页数-1)*每页条数**，对应就是6，3；偏移量是包含第0行的，相当于数组中index下标；

```sql
SELECT * FROM customers LIMIT 6,3
```

​	练习：获取积分排名前三顾客；

```sql
SELECT * FROM customers
ORDER BY points DESC
LIMIT 3
```
