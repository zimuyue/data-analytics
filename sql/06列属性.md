## 列属性

### 1.1 增删改

​	通过表中间图标“设置”，进入该表的设计模式；column（列名称）datatype（数据类型）PK（主键）NN（非空值）AI（自动递增）通常被应用在主键列，每当在表中插入一条记录时，将主键ID增加；

​	default / expression默认值，如果没有提供任何值MySQL会给这些标记的列直接填上指定的默认值；

### 1.2 插入单行

​	INSERT INTO语句，后指定插入哪张表数据；VALUES子句，然后在括号内写上表中每一列的值，以逗号分隔；主键ID列可以通过DEFAULT关键字，让MySQL生成一个顾客ID的唯一值（主键自动递增）

​	后续的列如果没有对应取值，通过NULL关键字省略该值；如果表设计中该列指定了default默认值，可以通过DEFAULT关键字使用默认值；

```sql
INSERT INTO customers
VALUES (DEFAULT,'John','Smith','1990-01-01',NULL,'address','city','CA',DEFAULT)
```

​	在表名称后，可以选择提供想要插入值的列；

```sql
INSERT INTO customers (
	first_name,
  last_name,
  birth_date,
  address,
  city,
  state
) VALUES (
	'John','Smith','1990-01-01','address','city','CA'
)
```

 ### 1.3 插入多行

​	插入多行，只需要在子句后用逗号接上另一组括号；

```sql
INSERT INTO shippers (name)
VALUES ('shipper1'),('shipper2'),('shipper3')
```

​	练习：在产品表插入3条记录；

```sql
INSERT INTO products (name, quantity_in_stock, unit_price)
VALUES ('Product1',10,1.95),('Product2',20,2.95),('Product3',30,3.95)
```

### 1.4 插入分层行

​	多表插入数据时，在“母子表”中主表每一条记录可能关联了子表中多条记录，在子表中例如order_id作为主键时，每当新增记录时id列自动递增或生成新的id，所以要获取主表中新生成的id作为主键插入子表中；

​	MySQL中有一套内置功能函数（function）例如LAST_INSERT_ID（最近插入id）返回插入新行时MySQL生成的id；

```sql
INSERT INTO orders (customer_id, order_date, status)
VALUES (1,'2019-01-02',1);
INSERT INTO order_items
VALUES (LAST_INSERT_ID(),1,1,2.95),(LAST_INSERT_ID(),2,1,3.95)
```

### 2.1 创建表复制

​	从一张表复制数据到另外一张表（备份表）通过CREATE TABLE AS语句，复制的表默认没有设置主键和自动递增列；

```sql
CREATE TABLE orders_archived AS
SELECT * FROM orders
```

​	子查询是属于另外一段SQL语句的选择语句，我们也可以在一段INSERT语句下用一段子查询；右键表选择Truncate Table清空表内所有内容；复制部分数据到新备份的表；

```sql
INSERT INTO orders_archived
SELECT * FROM orders WHERE order_date < '2019-01-01'
```

​	练习：在sql_invoicing数据库中复制invoices表中部分数据记录置于新表invoices_archive，这张表不要顾客id列，但需要顾客名称列（需连接客户表）同时通过payment_date列只复制支付过的发票；

```sql
CREATE TABLE invoices_archive AS
SELECT 
		i.invoice_id,
    i.number,
    c.name AS client,
    i.invoice_total,
    i.payment_total,
    i.invoice_date,
    i.due_date,
    i.payment_date
FROM invoices i
LEFT JOIN clients c USING(client_id)
WHERE i.payment_date IS NOT NULL
```
