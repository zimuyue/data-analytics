## 列属性

### 1.1 增删改

​	通过表中间图标“设置”，进入该表的设计模式；column（列名称）datatype（数据类型）PK（主键）NN（非空值）AI（自动递增）通常被应用在主键列，每当在表中插入一条记录时，将主键ID增加；

​	default / expression默认值，如果没有提供任何值MySQL会给这些标记的列直接填上指定的默认值；

### 1.2 插入单行

​	INSERT INTO语句，后指定插入哪张表数据；VALUES子句，然后在括号内写上表中每一列的值，以逗号分隔；主键ID列可以通过DEFAULT关键字，让MySQL生成一个顾客ID的唯一值（主键自动递增）

​	后续的列如果没有对应取值，通过NULL关键字省略该值；如果表设计中该列指定了default默认值，可以通过DEFAULT关键字使用默认值；

```sql
INSERT INTO customers
VALUES (DEFAULT,'John','Smith','1990-01-01',NULL,'address','city','CA',DEFAULT)
```

​	在表名称后，可以选择提供想要插入值的列；

```sql
INSERT INTO customers (
	first_name,
  last_name,
  birth_date,
  address,
  city,
  state
) VALUES ('John','Smith','1990-01-01','address','city','CA')
```

 ### 1.3 插入多行

​	插入多行，只需要在子句后用逗号接上另一组括号；

```sql
INSERT INTO shippers (name)
VALUES ('shipper1'),('shipper2'),('shipper3')
```

​	练习：在产品表插入3条记录；

```sql
INSERT INTO products (name, quantity_in_stock, unit_price)
VALUES ('Product1',10,1.95),('Product2',20,2.95),('Product3',30,3.95)
```

### 1.4 插入分层行

​	多表插入数据时，在“母子表”中主表每一条记录可能关联了子表中多条记录，在子表中例如order_id作为主键时，每当新增记录时id列自动递增或生成新的id，所以要获取主表中新生成的id作为主键插入子表中；

​	MySQL中有一套内置功能函数（function）例如LAST_INSERT_ID（最近插入id）返回插入新行时MySQL生成的id；

```sql
INSERT INTO orders (customer_id, order_date, status)
VALUES (1,'2019-01-02',1);
INSERT INTO order_items
VALUES (LAST_INSERT_ID(),1,1,2.95),(LAST_INSERT_ID(),2,1,3.95)
```

### 2.1 创建表复制

​	从一张表复制数据到另外一张表（备份表）通过CREATE TABLE AS语句，复制的表默认没有设置主键和自动递增列；

```sql
CREATE TABLE orders_archived AS
SELECT * FROM orders
```

​	子查询是属于另外一段SQL语句的选择语句，我们也可以在一段INSERT语句下用一段子查询；右键表选择Truncate Table清空表内所有内容；复制部分数据到新备份的表；

```sql
INSERT INTO orders_archived
SELECT * FROM orders WHERE order_date < '2019-01-01'
```

​	练习：在sql_invoicing数据库中复制invoices表中部分数据记录置于新表invoices_archive，这张表不要顾客id列，但需要顾客名称列（需连接客户表）同时通过payment_date列只复制支付过的发票；

```sql
CREATE TABLE invoices_archive AS
SELECT 
		i.invoice_id,
    i.number,
    c.name AS client,
    i.invoice_total,
    i.payment_total,
    i.invoice_date,
    i.due_date,
    i.payment_date
FROM invoices i
LEFT JOIN clients c USING(client_id)
WHERE i.payment_date IS NOT NULL
```

### 3.1 更新单行

​	通过UPDATE语句更新表中的一条或多条记录，SET子句用来指定一列或多列的新值，使用逗号添加更多列；

```sql
UPDATE invoices
-- SET payment_total = 10, payment_date = '2020-03-01'
-- SET payment_total = DEFAULT, payment_date = NULL
SET payment_total = invoice_total * 0.5, payment_date = due_date
WHERE invoice_id = 1
```

### 3.2 更新多行

​	在默认情况下MySQL工作台会在安全更新模式下运行，它允许每次更新一条记录；如果使用的是其他的客户端或应用程序代码，都不会出现此问题；解决：MySQL偏好设置SQL Editor底部Safe Updates取消勾选；

```sql
UPDATE invoices
SET
	payment_total = invoice_total * 0.5,
	payment_date = due_date
-- WHERE client_id = 3
WHERE client_id IN (3,4)
```

​	练习：在sql_store表中获取所有在1990年前出生的客户增加50点积分；

```sql
UPDATE customers SET points = points + 50
WHERE birth_date < '1990-01-01'
```

### 3.3 UPDATE子查询

​	通过子查询语句先找到更新的目标ID，再通过目标ID更新记录；子查询是在另一端SQL语句中的SELECT选择语句；

```sql
USE sql_invoicing;
UPDATE invoices
SET payment_total = invoice_total * 0.5, payment_date = due_date
WHERE client_id = (SELECT client_id FROM clients WHERE name = 'Myworks')
```

​	当子查询返回多条记录时，对应的UPDATE语句中WHERE子句等号要换成IN操作符；

```sql
USE sql_invoicing;
UPDATE invoices
SET payment_total = invoice_total * 0.5, payment_date = due_date
WHERE client_id IN (
	SELECT client_id FROM clients WHERE state IN ('CA','NY')
)
```

​	练习：在sql_store表中超过3000积分的顾客更新订单注释；

```sql
USE sql_store;
UPDATE orders o SET comments = 'Gold customer'
WHERE o.customer_id IN (
	SELECT customer_id FROM customers
    WHERE points > 3000
)
```

### 4.1 删除行

​	使用DELETE FROM语句用来删除记录，如果不加WHERE筛选条件，这条语句会删除表里的全部记录；

```sql
USE sql_invoicing;
DELETE FROM invoices
WHERE client_id = (
	SELECT o.client_id FROM clients o
    WHERE name = 'Myworks'
)
```
