## 聚合函数

### 1.1 函数

​	函数是一段封装好的可用代码，MySQL自带内置函数中有一些聚合函数，通过取系列值并聚合结果，导出单一结果值；例如MAX、MIN、AVG、SUM、COUNT这些函数都要使用括号来执行或调用；

```sql
SELECT
	MAX(invoice_total) AS highest,
	MIN(invoice_total) AS lowest,
	AVG(invoice_total) AS average,
	SUM(invoice_total) AS total,
	COUNT(invoice_total) AS number_of_invoices
FROM invoices
```

​	聚合函数只计算非空值，也就是说排除NULL的记录行；

```sql
SELECT
	COUNT(invoice_total) AS number_of_invoices,
	COUNT(payment_date) AS count_of_payments
FROM invoices
```

​	如果想要查询所有的记录数包含非空值NULL，需要使用COUNT(*)星号匹配；

```sql
SELECT COUNT(*) AS total_record FROM invoices
```

​	聚合函数括号内支持编写表达式，先得到参数列结果，如果是表达式形式再根据结果计算；

```sql
SELECT SUM(invoice_total * 1.1) AS total FROM invoices
```

​	默认情况下聚合函数是取所有记录包含重复记录，如果要排除重复项需要使用DISTINCT关键字；

```sql
SELECT COUNT(DISTINCT client_id) AS total_record FROM invoices
```

​	练习：聚合查询2019上半年、下半年与合计的销售金额、支付金额与差值；

```sql
SELECT
	'First half of 2019' AS date_range,
	SUM(invoice_total) AS total_sales,
    SUM(payment_total) AS total_payments,
    SUM(invoice_total - payment_total) AS what_we_expect
FROM invoices WHERE invoice_date BETWEEN '2019-01-01' AND '2019-06-30'
UNION
SELECT
	'Second half of 2019' AS date_range,
	SUM(invoice_total) AS total_sales,
    SUM(payment_total) AS total_payments,
    SUM(invoice_total - payment_total) AS what_we_expect
FROM invoices WHERE invoice_date BETWEEN '2019-07-01' AND '2019-12-31'
UNION
SELECT
	'Total' AS date_range,
	SUM(invoice_total) AS total_sales,
    SUM(payment_total) AS total_payments,
    SUM(invoice_total - payment_total) AS what_we_expect
FROM invoices WHERE invoice_date BETWEEN '2019-01-01' AND '2019-12-31'
```

### 2.1 GROUP BY子句

​	对一列或多列进行数据分组（按照指定的字段分组）GROUP BY子句紧跟在FROM、WHERE子句后ORDER BY子句之前；默认情况下，数据按照GROUP BY子句中指定的列排序；

```sql
SELECT client_id, SUM(invoice_total) AS total_sales
FROM invoices
-- WHERE invoice_date >= '2019-07-01'
GROUP BY client_id
ORDER BY total_sales DESC
```

​	多列分组，按照多列组合的形式展示数据；例如state与city每个州和城市的组合得到一条记录；

```sql
SELECT state, city, SUM(invoice_total) AS total_sales
FROM invoices JOIN clients USING(client_id)
GROUP BY state, city
```

​	练习：聚合查询date、payment_method、total_payments，组合日期与支付方式；（解决一个问题前，先把问题拆分成更小、更易解决的问题）

```sql
SELECT date, pm.name AS payment_method, SUM(amount) AS total_payments
FROM payments p JOIN payment_methods pm
ON p.payment_method = pm.payment_method_id
GROUP BY date, payment_method
ORDER BY date
```

### 2.2 HAVING子句

​	HAVING子句对分组结果进行条件筛选；为什么不用WHERE子句？因为WHERE子句是在GROUP BY子句前执行，此时还未对数据进行分组，所以使用HAVING子句；

​	WHERE与HAVING的区别：前者是通过对行记录进行条件筛选，后者是通过对分组结果进行筛选；

​	注意HAVING子句中用到的列，一定得是SELECT子句中存在的列；但在WHERE子句中可以用到任何列，无论是否在SELECT子句中；

```sql
SELECT client_id, SUM(invoice_total) AS total_sales, COUNT(*) AS number_of_invoices
FROM invoices
-- WHERE ...
-- GROUP BY client_id HAVING total_sales > 500
GROUP BY client_id HAVING total_sales > 500 AND number_of_invoices > 5
-- GROUP BY client_id HAVING invoices.payment_date x
```

​	练习：在sql_store数据库中聚合查询定位在VA的用户且消费超过100；（每当在SELECT语句中有聚合函数而且对数据分组，那么可以直接根据SELECT子句中所有列来分组）

```sql
SELECT
		c.customer_id,
    c.first_name,
    c.last_name,
    sum(oi.quantity * oi.unit_price) AS total_sales
FROM customers c
JOIN orders o USING(customer_id)
JOIN order_items oi USING(order_id)
WHERE state = 'VA'
GROUP BY c.customer_id, c.first_name, c.last_name
HAVING total_sales > 100
```
