## 聚合函数

### 1.1 函数

​	函数是一段封装好的可用代码，MySQL自带内置函数中有一些聚合函数，通过取系列值并聚合结果，导出单一结果值；例如MAX、MIN、AVG、SUM、COUNT这些函数都要使用括号来执行或调用；

```sql
SELECT
	MAX(invoice_total) AS highest,
	MIN(invoice_total) AS lowest,
	AVG(invoice_total) AS average,
	SUM(invoice_total) AS total,
	COUNT(invoice_total) AS number_of_invoices
FROM invoices
```

 	聚合函数只计算非空值，也就是说排除NULL的记录行；

```sql
SELECT
	COUNT(invoice_total) AS number_of_invoices,
	COUNT(payment_date) AS count_of_payments
FROM invoices
```

 	如果想要查询所有的记录数包含非空值NULL，需要使用COUNT(*)星号匹配；

```sql
SELECT COUNT(*) AS total_record FROM invoices
```

​	聚合函数括号内支持编写表达式，这个函数形式与JS中的函数参数不一样，聚合函数是先得到参数列结果，如果是表达式形式再根据结果计算，这里需要注意与JS函数参数不同，JS中是先计算表达式结果后执行函数；

```sql
SELECT SUM(invoice_total * 1.1) AS total FROM invoices
```

​	默认情况下聚合函数是取所有记录包含重复记录，如果要排除重复项需要使用DISTINCT关键字；

```sql
SELECT COUNT(DISTINCT client_id) AS total_record FROM invoices
```

​	练习：聚合查询2019上半年、下半年与合计的销售金额、支付金额与差值；

```sql
SELECT
	'First half of 2019' AS date_range,
	SUM(invoice_total) AS total_sales,
    SUM(payment_total) AS total_payments,
    SUM(invoice_total - payment_total) AS what_we_expect
FROM invoices WHERE invoice_date BETWEEN '2019-01-01' AND '2019-06-30'
UNION
SELECT
	'Second half of 2019' AS date_range,
	SUM(invoice_total) AS total_sales,
    SUM(payment_total) AS total_payments,
    SUM(invoice_total - payment_total) AS what_we_expect
FROM invoices WHERE invoice_date BETWEEN '2019-07-01' AND '2019-12-31'
UNION
SELECT
	'Total' AS date_range,
	SUM(invoice_total) AS total_sales,
    SUM(payment_total) AS total_payments,
    SUM(invoice_total - payment_total) AS what_we_expect
FROM invoices WHERE invoice_date BETWEEN '2019-01-01' AND '2019-12-31'
```
