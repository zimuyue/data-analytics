## 视图

### 1.1 创建视图

​	当查询语句越写越复杂（多个连接和子查询）可以将这些查询或子查询存到视图，简化SELECT语句，复用存在视图中的查询语句；通过CREATE VIEW来创建视图对象，在数据库中Views中查看已创建的视图对象；

​	视图的作用很像一张虚拟表，但是视图不存储数据，数据依然存放在源表中，类似于映射关系，通过视图功能提供了一张基础表；

```sql
CREATE VIEW sales_by_client AS
SELECT c.client_id, c.name, sum(invoice_total) AS total_sales
FROM clients c JOIN invoices i USING(client_id)
GROUP BY client_id, name
```

​	练习：创建客户结余clients_balance视图，包含client_id、name、balance，结余计算方式发票表中的发票总额减支付总额；

```sql
CREATE VIEW clients_balance AS
SELECT
	c.client_id,
	c.name,
	sum(invoice_total - payment_total) AS balance
FROM clients c JOIN invoices USING(client_id)
GROUP BY client_id, name
```
