## 认识数据库

### 1.1 什么是数据库（Database）

​	数据库是一个以可轻易获取形式来存储的数据集合，为了管理数据库，我们可使用数据库管理系统或DBMS（Database Management System）的软件应用，通过连接到一个DBMS然后下达查询或修改数据的指令，DBMS就会执行该指令并返回结果；

### 1.2 数据库分类

​	关系型数据库（Relational）和非关系型数据库（NoSql）

​	关系型数据库，数据存储在利用关系相互链接的表中，每张表会存储一类特定对象的数据（顾客、产品、订单等）SQL或者SQUEL是用来处理这些关系型DBMS的语言，用SQL来查询或修改数据；

```sql
SELECT *
FROM products
WHERE category = "food"
ORDER BY price
```

​	常用的关系型数据库：MySQL、SQL Server、Oracle；

​	每种DBMS的SQL语言风格略有不同，操作相似都是基于标准SQL规范；

​	非关系型数据库（mongoDB），没有表或者关系，非关系型DBMS无法读取SQL语言，有自己的查询语言；

### 1.3 SQL与SQUEL历史

​	SQL最初是由IBM在70年代开发的，最开始它被称作SQUEL即结构化英语查询语言的缩写（Structured English Query Language）改成SQL是因为最初它是一种飞机的商标；
